# Service page images: one size for each kind

All 14 service pages use the same picture sizes. Make each kind of picture once at the size
below, for every page. Save it with the same file name in the page's folder (replacing the old
file) and the page shows it, no code change needed.

| Kind of picture | Make at (px) | Ratio | File name |
|---|---|---|---|
| **Banner (hero)**, 1 per page | **3072 x 864** | 32 : 9 | hero.jpg (Website Development: wd-hero.jpg) |
| **Intro picture**, 1 per page | **1260 x 630** | 2 : 1 | intro.jpg (Website Development: wd-intro.jpg) |
| **Service card picture**, 6 to 8 per page | **1440 x 408** | 60 : 17 | see the list below (c1.jpg, k1.jpg, s1.jpg ...) |
| **Bottom info card picture**, 2 per page | **1440 x 330** | 48 : 11 | see the list below |

- The CTA bar at the bottom is drawn by the code (purple to orange gradient). No picture needed.
- Rounded corners and the soft shadow of every card come from the code: make the pictures as
  plain rectangles, without corners or shadow.
- Keep the text area empty, the text is real text on top:
  - banner: left half (heading, text, buttons). Every service page uses the same banner design
    (same height, text style and buttons), so make every banner the same way: light, soft picture,
    no wave or curve at the bottom (the banner ends in a straight line), no text in the picture;
  - service and info cards: left ~55% (card title and text); the picture goes on the right.
  - intro picture: no text on it.
- Not part of the standard (kept from the reference, no need to make): category strip (cats.jpg,
  plat.jpg, types.jpg), process strip (proc.jpg), checklist box (check.jpg / checks.jpg),
  Website Development page bands.


## Services page cards use the banner

Each card on the Services page shows the **banner (hero.jpg) of its own detail page**,
automatically. There is no separate card picture to make. If a service has no banner yet,
the card falls back to its old card photo (assets/images/services-page/svc-XX.jpg).

The card is narrower than the banner, so it shows only the **right-hand part** of the banner,
at full height. When making a banner (3072 x 864):

- Put the main object (laptop, phone, icon...) inside the **right 1024 px** (x 2048 to 3072).
  That part shows in every card, on laptop and on phone.
- Keep the most important part of that object in the **top ~60%**: the card title and text sit on
  the bottom of the card.
- The left half stays empty for the banner text.
