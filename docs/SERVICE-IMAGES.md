# Service page images: sizes

Every picture on the 14 service pages, with the size to make it at.

- **Make at** = the size to create the new image. It is 3x the reference size: the page shows pictures up to 1.5x on big screens, and 2x more keeps them sharp on high-resolution (retina) screens.
- **Minimum** = 2x the reference size (the size of the current files).
- Keep the same width : height ratio. Leave the text area of each picture empty: all text is real text on top.
- Banners: the left ~45% holds the text, keep it calm; the picture fills the full screen width.
- File names and folders stay the same, so a new image can simply replace the old one (same name, .jpg).
